t02 — Verifying the downloads against the published checksums

The published checksums file lists every asset in the form
"<sha256> *<filename>". The lab filtered it to the files it
downloaded (that filter is the lab's verify-downloads.sh),
then ran sha256sum in check mode:

$ sha256sum -c lab-checksums.txt
autoexec.ipxe: OK
netboot.xyz-snp.efi: OK
netboot.xyz-undionly.kpxe: OK
netboot.xyz.efi: OK
netboot.xyz.img: OK
netboot.xyz.iso: OK
netboot.xyz.kpxe: OK
netboot.xyz.lkrn: OK
